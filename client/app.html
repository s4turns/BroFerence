Changelog

v2.5 2026-09-08
  • Moderators and the room owner can now stop someone else's screen share, instead of having to kick them over it
  • The button shows up on the sharer's tiles only while they are actually sharing, and they can start a new share straight after
  • New glitchy cyberpunk logo in the top bar, which recolours to match whichever theme you are using
v2.4 2026-09-08
  • Signaling now defaults to WebSocket — QUIC is still there under Options → Signaling if you want it, and your own pick is left alone
  • Fixed people getting stuck in the room after leaving on QUIC — a closed tab or a dropped connection now clears properly instead of leaving a frozen tile behind
  • Closing a tab says goodbye straight away rather than waiting to time out
  • A dropped peer's tile is held for 10s under a DISCONNECTED countdown, and that also shows when your own connection drops
v2.3 2026-08-29
  • The signaling choice is now on the mic/camera setup screen too, so you can pick it before joining without opening Options
  • Both controls stay in step — changing one updates the other
  • Quieter server logs: QUIC handshake chatter no longer fills the signaling log
v2.2 2026-08-28
  • Signaling can now run over QUIC (WebTransport) instead of a WebSocket — pick it under Options → Signaling
  • Auto mode tries QUIC and falls back to WebSocket on its own, so nothing changes if QUIC is unavailable
  • The status bar shows which transport your session is actually using
  • Safari and iOS have no WebTransport, so they keep using WebSocket exactly as before
  • Video and audio are unchanged — only signaling moved
  • A signaling connection that dropped before registering could leave the client stuck never reconnecting
v2.1 2026-08-19
  • Fixed Safari and iOS never showing the camera/microphone prompt
  • In-app browsers (Instagram, Facebook, TikTok, WeChat) are now detected and explained — open the link in Safari or Chrome
  • If the prompt goes unanswered, the page points you at the padlock icon in your address bar
  • Blocked and dismissed permissions now give different, accurate instructions
  • A non-HTTPS page now says that is why your devices are unavailable
v2.0 2026-08-19
  • Fixed invisible buttons and click handling on video tiles
  • Dev environment now serves on 443/8765 like prod
  • Screen share waits for the presenter slot before broadcasting
  • 60-second countdown warns everyone before a deploy restarts the server
  • Room owner is now the sole encryption key authority
  • IRC bridge reconnects reliably — correct cert hostname and an accepted nick
  • Join without a mic or camera — missing, blocked, or busy devices no longer block the room
  • Prejoin says which device is missing and why, instead of a dead-end alert
  • After the restart countdown, the page reloads itself as soon as the server is back
  • Fixed browsers caching the page and showing an old version after an update
  • Chat button no longer draws a box around its own icon
v1.9 2026-08-18

  • ~80 emoji replaced with inline SVG icons that follow each theme
